# Checkpoint: integrated browser review

- **Work branch:** `local-ui-review`
- **Scope:** local Windows runtime and Homeostat browser behavior
- **Remote publication:** none; no remote branch or pull request was created

## Issues found and fixed

1. `scripts/with-app-env.mjs` passed the bare `vite` command to
   `child_process.spawn`. On Windows this could not launch the npm `.cmd`
   shim. The wrapper now resolves the local Vite shim and uses the Windows
   shell only for that command, leaving direct Node child processes unchanged.
2. A seeded field reported `Viability 0.00` until the first simulation step.
   The existing `Metrics` display and the local triage agent consequently
   treated a healthy seeded field as a collapse. `SimEngine.seed()` now
   computes baseline population, entropy, heat, energy, and viability.
3. The symlink wrapper test now skips explicitly when Windows symbolic-link
   privileges are unavailable instead of failing for an environment limitation.

## Browser review

The integrated browser loaded the local app at `http://127.0.0.1:8080/`,
showed visible Homeostat content, and exercised Run plus World controls. The
seeded field displayed a non-zero viability and the World preset/settings
controls updated while the simulation ran.
